## 汇率、手续费和续费的真实情况

**汇率怎么算。** 结账页标的是美元，实际扣多少人民币由支付宝按当日汇率折算，这一步在支付宝侧完成，商家不参与定价。下单前你能看到的确认页金额就是最终金额，觉得汇率不合适的，可以对比一下银联通道，日常小单子差别不大。

**有没有额外手续费。** 支付宝跨境付款本身不额外收通道费，商家也不会因为选了支付宝就加价。真正需要注意的是你的账户额度。

**限额卡在谁那里。** 单笔限额取决于你的支付宝账户等级和设置，跟商家无关。普通账户单笔几千元人民币没问题，$53.6/月 这种顶配折合人民币不到 400 元，任何账户都够。要买年付或多台，提前在支付宝里看一眼单笔和单日限额，不够就先提额。

**续费会不会涨价。** LightLayer 在促销公告和产品线调整通知里都写明，已经购买的套餐续费价不变，2026 年 9 月那次调整也只影响新购，老用户的配置和续费价格原样保留。这一点比很多首年低价、次年翻倍的商家省心。

**扫码支付和自动续费的冲突。** 扫码是一次性授权，系统拿不到长期扣款权限，所以这类付款方式通常开不了自动续费。用支付宝的，把到期提醒邮件当续费闹钟，提前一周手动操作。忘记续费的后果是机器被停、数据按条款处理，不是补个款就能立刻恢复的。

## 三条洛杉矶线路，选错比买贵更亏
